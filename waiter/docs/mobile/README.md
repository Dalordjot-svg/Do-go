# Мобильные сценарии COFFEEMAN Waiter

Снимки сделаны в Playwright с профилями iPhone 15 и Pixel 7 и демонстрационными данными.

- [iPhone · WebKit](iphone.png)
- [Android · Chromium](android.png)

Проверены выбор заказа и его содержимое, выбор стола по зоне, счётчик гостей, меню конкретного гостя, отправка, перевод позиции в стоп-лист и периоды в профиле. Сценарий уменьшает высоту окна во время работы с меню и проверяет, что кнопка отправки остаётся видимой. Переходы учитывают системную настройку уменьшения движения.

Для повторного запуска установите браузеры Playwright и выполните `npm run test:mobile` из waiter/.
