# Изменения

## 0.1.0

- Изолированный проект COFFEEMAN Waiter под waiter/ с PWA и обязательным экраном установки.
- Карта зала, заказы по гостям, стоп-лист, тестовый расчёт и пересменка.
- Постоянная очередь, транзакционная синхронизация через Firebase Emulator и кеш сообщений.
- Академия Саши, практический экзамен и локальный сертификат.
- Настраиваемая диагностика облачной RTDB serverist-89be5.

- Публичная сборка размещена в waiter/ для существующей конфигурации Pages. Исходный HTML Vite хранится в src/.
