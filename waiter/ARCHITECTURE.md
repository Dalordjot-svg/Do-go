# Архитектура

Отдельное Vite PWA с относительными путями и областью действия в директории публикации. Локальное хранилище IndexedDB отделяет подтверждённый снимок от очереди команд. Команды имеют устойчивый идентификатор и переигрываются поверх подтверждённого снимка только для некритических действий.

Для тестовой RTDB одна транзакционная область workspaces/{branch} содержит занятость столов, операции по остаткам, заказы и журнал. Команда меняет только затронутые сущности в актуальном состоянии и выполняется атомарно с отметкой обработки. Объём записи RTDB равен области транзакции. Перед использованием с длительной историей нужна стратегия архивации и очистки квитанций. Чаты и присутствие размещены отдельно. Академия и её сертификаты локальны.
